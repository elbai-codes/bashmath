# Bashmath
Welcome to bashmath calculator
## Installation
First change to home directory using ``cd``  
``cd ~/``  
Second clone the repo using ``git``  
``git clone https://github.com/elbai-codes/bashmath``  
Then change into bashmath directory that ``git`` just created using ``cd`` again  
``cd ./bashmath``  
And then give the bashmath script execute permission using ``chmod``  
``chmod +x ./bashmath.sh``  
Finally run the script  
``./bashmath.sh``
## How to calculate
So far Bashmath can only do four operations  
Addition +  
Subtraction -  
Multiplication *  
Division /  
Anyways the terminal will lead you through the process
